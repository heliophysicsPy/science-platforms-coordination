# Science Platforms Coordination Base Image
## (For ESA Datalabs)

A Docker image inspired by HelioCloud's base image to be used by the Science Platforms Coordination IHDEA working group.

Note that the files here are based on the source files from the [heliocloud-base-2025-update branch](https://github.com/heliophysicsPy/science-platforms-coordination/tree/heliocloud-base-2025-update).
